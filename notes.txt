        1. lahman database - season level batting/pitching/fielding/team back to 1871
        2. retrosheet - play by play/event data 
        3. mlb stats api - live data
        3. baseball savant/statcast - pybaseball

- Chunking per source type
    - rules
    - articles
    - box scores/game logs
    - statcast
